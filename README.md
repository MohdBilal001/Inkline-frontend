# Inkline - Frontend

Inkline is a modern blogging platform frontend built with React and Vite. It provides a clean reading and writing experience with authentication, article publishing, user profiles, avatars, article cover images, and integration with a Spring Boot backend.

## Features

- User registration and login
- JWT authentication
- Create and publish articles
- Read published articles
- User profiles
- Profile avatar uploads
- Article cover image uploads
- Article claps
- Responsive desktop and mobile interface
- React Router navigation
- REST API integration
- Cloudinary image storage
- Spring Boot backend integration

## Tech Stack

- React 18
- Vite
- JavaScript
- React Router
- Tailwind CSS
- JWT Authentication
- Cloudinary
- Spring Boot REST API
- MySQL
